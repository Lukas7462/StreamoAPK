# Streamo – APK

Aktuelle Version der Streamo-App für Fire TV und Android TV.

- **Download:** [streamo.apk](https://raw.githubusercontent.com/Lukas7462/StreamoAPK/main/streamo.apk)
- Versionsinfo: `version.json`

Installation auf dem Fire TV: Entwickleroptionen → „Apps unbekannter Herkunft“ für die Downloader-App erlauben,
in Downloader die Download-Adresse oben eingeben und installieren. Danach in Streamo unter
**Einstellungen → Quellen** den IPTV-Zugang eintragen.

Updates: In der App unter **Einstellungen → Update**.
